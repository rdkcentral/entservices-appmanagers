What is RALF?

RALF is the RDK application package format implemented by ralf-utils (libralf). A RALF package is a signed archive containing an OCI image layout whose payload is an EROFS filesystem image protected by dm-verity. Instead of extracting files (as with EntOS ZIP widgets) the image is mounted read-only and verified block-by-block while being read.

Package type is detected by content: ralf::Package::detectPackageFormat(path) == Format::Ralf. A RALF archive lives in the same <packagesDir>/<appId>/package.wgt slot as a ZIP widget.

Mode 1 – ZIP native

unchanged

Extracted widget bind-mounted at /package, data.img loop-mounted. Per-app uid.

Mode 2 – ZIP app + ZIP runtime

unchanged

Runtime extracted, bind-mounted at /runtime; args /runtime/<execFilePath>.

Mode 3 – ZIP app + RALF runtime

new

e.g. YouTube widget + com.sky.cobalt. RalfPackageHandler::lockRuntime() mounts the runtime with libralf; runtimePath = EROFS mount, command = runtime entryPoint. Lock fails cleanly if the runtime cannot be mounted.

Mode 3b – ZIP app on RALF runtime with base

new

As in AI1, a runtime that depends on a base turns the widget into the top layer of an OCI bundle: manifest [base, runtime, widget], synthetic widget layer config (permissions from capabilities), widget data.img at /home/private, env from entos sysconfig.

Mode 4 – base-free RALF

new

Manifest has 1–2 layers ([runtime, application]). RuntimeManager rewrites appPath/runtimePath/command and uses the classic DobbySpecGenerator with the app's own uid, networking + appservicesrdk plugins.

Mode 5 – RALF OCI bundle

existing, extended

overlayfs app:runtime:[vendor]:base + RalfOCIConfigGenerator; StartContainer(bundle). EntOS adds the vendor GPU layer and base-init process args.

Mode 6 – disabled

rejected

ralfEnabled=false or non-RALF RuntimeManager → ERROR_UNAVAILABLE / ERROR_RALF_DISABLED.

The ZIP-app + RALF-runtime fix

Before: loadPackage(com.sky.cobalt) ran the ZIP extractor → package widget is missing files (signature1.xml no / config.xml no) → can't find runtimePackage → Lock still returned SUCCESS with empty runtime.
After: PackageImpl::Lock checks isRalfPackageInstalled(runtimeId) and calls RalfPackageHandler::lockRuntime() (same libralf mount as RALF apps). Failure now fails the lock. The runtime is released by Unlock() via LockedWidget.ralfRuntime.
